# Research and licences

This migration used the following projects as behavioural/research references:

- AC6_recomp — Ace Combat 6-specific analysis and compatibility research.
- ReXGlue — configuration semantics and prior static-recomp integration experience.
- Xenia — Xbox 360/Xenos behavioural reference.
- XenonRecomp — PowerPC static recompilation research.
- XenosRecomp — Xenos shader/graphics recompilation research.
- Unleashed Recompiled — production game-recomp/module integration reference.
- Dead Rising 2 Case Zero / Case West Xenon recomp projects — contemporary Xenon-recomp project structure references.

No implementation source from those projects is copied into this repository by this migration. The migrated material is project-specific metadata (addresses, generated symbol labels and classifications) derived from the public AC6 configuration, plus original integration code written against Project Xenon's public APIs.

Project Gracemeria remains MIT-licensed. Third-party projects retain their own licences; consult those repositories before reusing source in future work.
